Genre and authorship classification · Research, in progress

Can a computer tell who wrote a text, or what kind of page it is?

Athanasios Bonis Rebuild of a 2019 University of the Aegean thesis Status: classical baselines complete, pretrained models next

Summary

This project compares methods for two text-sorting tasks: identifying the genre of a web page and attributing a text to one of several candidate authors when the topic changes. Every method runs under one protocol in which nothing is learned from test data. The first round covers the classical methods. Character n-grams with a linear SVM reach 97.2% accuracy on the 7-genre corpus, but only 58.2 macro-F1 on cross-domain authorship (PAN-18), where the best score falls to 46.5 for Polish. The next rounds test whether pretrained models and LLMs close that gap.

Try the task before reading about it

Eight short rounds. Guess the author or the page type, then see what a letter-counting model guessed for the same text.

§1

The two tasks

Both are closed-set classification. The model receives a text and must assign it one label from a fixed list.

Web genre identification

What kind of page is this?

Blog, online shop, FAQ, news front page, personal home page, search results. Search engines and dataset builders use genre to filter and organise the web.

Cross-domain authorship attribution

Which candidate wrote this?

Each candidate has seven known texts on one topic. The unknown texts are on a different topic, so the model has to follow the writer and ignore the subject.

§2

Measuring style with character n-grams

The oldest strong baseline cuts a text into overlapping slices of three characters and counts them. "the cat" becomes the, he·, e·c, ·ca, cat. The counts form a profile that captures function words, punctuation habits, spelling and word endings, which are less tied to topic than vocabulary is.

§4

Evaluation protocol

A score is only meaningful if the model never saw the test texts while learning. When it does, the error is called data leakage, and it inflates results. These rules apply to every model and are enforced in code where possible.

  1. Train-only learningEnforced

    Vocabularies, scalers, embeddings, language-model adaptation and prompt examples come from the training part of each split only.

  2. No tuning on test dataEnforced

    Hyperparameters live in versioned configs. Any tuning uses validation data carved from the training split.

  3. Official metricsEnforced

    Accuracy and macro-F1 for every split. PAN-18 uses macro-F1 over candidates, averaged over problems, also per language.

  4. VarianceEnforced

    Mean ± standard deviation over splits, with three CV seeds on the genre corpora.

  5. SignificanceTo do

    Paired Wilcoxon signed-rank tests over identical splits, corrected for multiple comparisons.

  6. CostEnforced

    Fit and predict time per split, hardware, and API cost where relevant.

  7. ProvenanceEnforced

    Every run records its config, git commit and package versions.

Results: classical baselines

97.2%

Character n-grams + SVM sort 7-genre pages almost perfectly. KI-04 is harder, at 85.0%.

58.4F1

Cross-topic authorship stays hard. The two n-gram methods tie, and both are weakest in Polish.

13.4F1

fastText fails on authorship. Seven texts per candidate are too few for it to learn word-level signals.

§6

Background

  1. 2019

    The original thesis

    ULMFiT was applied to both tasks. It reported 99.1% on 7-genre and 92.6% on KI-04, and losses against n-gram baselines on authorship.

  2. 2026

    Review

    Test accuracy exceeded validation accuracy on both genre corpora, which suggests the language model was adapted on text that included test pages. PAN-18 numbers were inconsistent, an English-only model was applied to four other languages, and most code was missing.

  3. Now

    Rebuild

    The thesis is motivation only. Every number on this page comes from code in the repository, re-run under the protocol in §4.

  4. Next

    Pretrained models and LLMs

    Test tiers 1–3 under the same protocol and answer the main question: has pretraining overtaken character n-grams on cross-topic authorship?

§7

Terms

Character n-gram
A slice of n consecutive characters. "the" and "he·" are 3-grams.
Data leakage
Test material reaching the training step, which inflates scores.
Cross-validation
Rotating which part of the data is the test set, then averaging.
Accuracy
The share of predictions that are correct.
Macro-F1
F1 computed per class, then averaged, so rare classes count as much as common ones.
Cross-domain
Training and test texts come from different topics.
Pretrained model
A model that learned general language from large text collections before seeing this task.
PAN
A shared-task series on authorship and stylometry, held at CLEF.
